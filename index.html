자료 01

웹 제안서

제출 제안서의 핵심을 10개 섹션과 부록으로 정리했습니다. 과제 진단과 설계 관점부터 기간·예산, 일정·인력, 개발 범위, 품질 관리, 유지보수 계획까지 확인하실 수 있습니다.

  • 법정 서류 항목을 「양식 항목 정의서」 한 곳에서 관리하고, 입력 화면·저장 구조·엑셀 출력을 그 정의에서 만드는 구조 — 다섯 단계 QC와 측정 조건을 명시한 인수 기준 11개 항목
  • 공고의 필수 과업 9개를 모두 포함한 90일·100.0 MD 계획 — 전체 범위 추정치(115~140 MD) 하한의 87.0%이며, 부족한 15.0 MD는 화면 표현과 출력 형식의 상세 수준을 조정해 맞추고 QC 공수는 줄이지 않았습니다
  • 「아직 정하지 않은 범위」 3건(양식 전달 형태 · 기술 스택 · 서버 구성)의 권장안과 비용 차이, 월 운영 비용의 인프라 이용료 · 운영 관리비 · 장애 대응 범위 구분
  • 투입 인력 7명(전원 보유 인력), 단계별 승인 4회, 검수 완료 후 하자보수 6개월 무상

자료 02

작업안전 통합관리 화면

제안한 서비스의 관리 웹(관리자 · 작업관리자 · 안전관리자 · 협력업체)과 작업자 모바일 화면을 직접 조작해 보실 수 있습니다. 작업 배정부터 안전 확인 · 완료 보고까지 업무 흐름을 따라 살펴볼 수 있습니다. 화면의 회사명·현장·인물·수치는 모두 가상의 예시입니다.

  • 첫 접속 시 로그인 화면이 열립니다. 업무 영역을 고른 뒤 「체험 계정」에서 계정을 누르면 이메일과 비밀번호가 채워지고, 「로그인」을 누르면 접속됩니다. 로그인 상태가 유지되어 있으면 업무 화면으로 바로 이동합니다
  • 작업 배정 → 작업자 본인 확인(휴대전화 뒤 4자리) → 필수 안전 점검 → 개인 승인 → 작업관리자 시작 승인 → 완료 보고. 모든 작업자의 안전 확인이 완료되어야 시작할 수 있으며, 허가 대상 작업은 유효한 작업허가도 필요합니다
  • 양식 정의서 한 곳에서 입력 화면 · 저장 검증 · 엑셀 출력을 만들고, 양식 검증 화면에서 항목별 화면 · 저장 · 엑셀 위치를 대조합니다. 양식이 개정되어도 과거 서류는 작성 당시 버전으로 열립니다
  • 협력업체 작업허가의 신청 · 보완 요청 · 재신청 · 승인과 차수 비교, 서류 엑셀(.xlsx) 내려받기와 사진을 포함한 파일 묶음(.zip)

관리 웹 바로 가기 작업자 작업 확인 화면 바로 가기
검색 노출을 제한했지만, 주소를 아는 사람은 누구나 열 수 있습니다.

모든 페이지에 검색 엔진에 색인하지 말 것을 요청하는 설정(noindex)을 적용했으나 별도의 접근 제한은 없습니다. 제안 금액 등 민감한 정보가 포함되어 있으니 발주처 내부 관계자에게만 공유해 주시기 바랍니다.

서비스 화면에 표시되는 회사·현장·인물·수치는 모두 가상의 예시입니다.

고객사·현장·협력업체·작업자 정보와 전화번호는 가상의 자료이며 실제 기업과 관계가 없습니다. 화면에 쓰인 사진은 시연용으로 생성한 이미지이며 실제 시설이나 현장 증빙이 아닙니다. 알림톡은 실제로 발송되지 않습니다. 화면에서 변경한 값과 로그인 상태는 지금 사용 중인 브라우저에만 저장되며, 다른 사람의 화면이나 서버에는 반영되지 않습니다. 처음 상태로 되돌리려면 로그인 화면의 「체험 데이터 초기화」를 눌러 주세요.

서류 양식과 일부 설정값은 협의 전 가정값이며, 정확한 개발 범위는 웹 제안서를 기준으로 합니다.

안전 서류 기본 6종의 항목과 「근거」 칸은 시연용 예시이며, 법적으로 갖춰야 하는 항목은 발주처(또는 고객사)가 양식 항목 정의서에서 확정합니다. 작업자 본인 확인(휴대전화 뒤 4자리)은 간편 확인이며, 추가 인증 필요 여부는 계약 전에 협의합니다. 다국어 화면, 통계 리포트 화면, 앱 개발은 1차 개발 범위에 포함되지 않습니다. 원본 서식 재현은 대표 1종을 포함하며, 추가 양식은 별도 견적입니다. 알림톡 발송료는 개발비와 별도로 부담합니다. 각 항목의 근거는 웹 제안서의 「기간·예산」·「개발 범위」 섹션에서 확인하실 수 있습니다.
